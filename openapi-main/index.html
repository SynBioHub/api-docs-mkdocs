    User¶

    POST /login¶

    Login

    Description

    This POST request requires email (or username)/password and returns a user token that should be passed in the X-authorization header to view private objects and submit new objects, etc.

    Input parameters

    Parameter In Type Default Nullable Description
    Accept header string text/plain No Content type expected by the client, must be text/plain

    Request body

    {
    "email": "user@example.org",
    "password": "password123"
}
    Schema of the request body 
    {
    "type": "object",
    "properties": {
        "email": {
            "type": "string"
        },
        "password": {
            "type": "string"
        }
    },
    "required": [
        "email",
        "password"
    ]
}

    Responses

    "fb767104-6294-4d8b-9800-994f1076b1f1"
    Schema of the response body 
    {
    "type": "string"
