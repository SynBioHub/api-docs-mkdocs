    SynBioHub Plugins API¶

    This page documents the standardized API that all SynBioHub plugins must implement.

    !!! tip "What are Plugins?" If you are new to SynBioHub plugins, read our Plugin Concept Guide to understand how they work and the different types available.

    SynBioHub Plugins API 1.0.0¶

    Plugin-related API endpoints for SynBioHub

    For a detailed overview of how plugins work and how to implement them, see the Plugin Concept Guide.

    Servers¶

    Description URL
    Main SynBioHub instance https://synbiohub.org
    Local development instance http://localhost:7777

    Endpoints¶

    GET /status¶

    Plugin Status

    Description

    Checks if the plugin is operational. SynBioHub polls this endpoint to verify the plugin is up.

    Responses

    "The plugin is up and running"
    ⚠️ This example has been generated automatically from the schema and it is not accurate. Refer to the schema for more information.

    Schema of the response body 
    {
    "type": "string",
    "example": "The plugin is up and running"
}

    POST /evaluate¶

    Evaluate Request

    Description

    Determines if the plugin can handle the incoming request. SynBioHub sends metadata about the object or file to this endpoint. Return 200 if the plugin can process it, or 415 if it cannot.

    Request body

    {
    "type": "string",
    "url": "string",
    "filename": "string"
}
    ⚠️ This example has been generated automatically and is generic.

    Schema of the request body 
    {
    "type": "object",
    "properties": {
        "type": {
            "type": "string",
            "description": "The RDF type of the object (e.g., ComponentDefinition, Collection)"
        },
        "url": {
            "type": "string",
            "description": "The URL of the object in SynBioHub"
        },
        "filename": {
            "type": "string",
            "description": "Name of the file (for submission plugins)"
        }
    }
}

    Responses

    POST /run¶

    Run Plugin

    Description

    Executes the plugin logic. SynBioHub sends the actual data or location of the data to this endpoint.

    Request body

    {
    "url": "string",
    "complete_sbol": "string",
    "params": {}
}
    ⚠️ This example has been generated automatically and is generic.

    Schema of the request body 
    {
    "type": "object",
    "properties": {
        "url": {
            "type": "string",
            "description": "The URL of the object"

            "type": "string",
            "description": "URL to fetch the complete SBOL data"
        },
        "params": {
            "type": "object",
            "description": "Any additional parameters passed from the frontend"

}
